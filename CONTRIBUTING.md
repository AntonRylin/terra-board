# Contributing to Terra Board

Thanks for wanting to help. Terra Board is open source under the [MIT license](LICENSE): you can copy, fork and change it in your own copy. Changes to this repository go through pull requests, and the maintainer reviews and merges each one.

## Before you start

- **Bugs:** open an [issue](https://github.com/AntonRylin/terra-board/issues) with the steps to reproduce it, what you expected and what happened.
- **Features or larger changes:** open an issue or ask on [Discord](https://discord.gg/GNJX5y9tux) first, so you don't spend time on something that won't be merged.

## Making a change

1. Fork the repository and create a branch from `codex/local-canvas`.
2. Set up the project with `npm ci` and run it with `npm run dev`. See [docs/development.md](docs/development.md) for details.
3. Keep the pull request focused on one change.
4. Run `npm test` and `npm run build` before you open the pull request.
5. Open the pull request and fill in the template.

## Review

Every pull request needs the maintainer's approval before it can be merged. Pull requests may be changed, asked to change, or declined to keep the app consistent. Automated checks on pull requests from outside contributors run only after the maintainer approves them.

By submitting a pull request you agree that your contribution is licensed under the MIT license.
