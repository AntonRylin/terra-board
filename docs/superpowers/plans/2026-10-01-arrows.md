# Editable arrows

Scope: Arrow toolbar tool (A), pointer drag creation, movable endpoints, insertable/removable bend points, smooth/straight/elbow routes, solid/dashed/dotted strokes, color and width, start/end marker choices and swap, editable midpoint label. Existing move/group/scale/clipboard/history and board transfer must preserve arrows. Connectors are freely positioned; automatic attachment/routing around objects is outside this request.

1. Add normalized arrow point/style data to model and validate it at storage and clipboard boundaries. Test persistence, transfer, invalid data and geometry.
2. Implement pure arrow path/handle/hit helpers and Pixi rendering with bounded curve samples; keep dimensions valid for horizontal/vertical arrows and scale normalized coordinates with existing transforms.
3. Integrate draw and point gestures into engine history/cancel, selection handles and hit testing. Include zoom and reverse-direction drawing tests.
4. Add Arrow tool and focused selection controls with accessible labels; text editing commits on Enter/blur and cancels on Escape.
5. Build, run automated tests and packaged mouse interactions on a disposable library; inspect screenshot, commit, reopen user's app.
