Terra Board for Linux (beta)

The same free whiteboard as on Windows, for 64-bit Linux. It works offline and keeps your boards in ~/.local/share/Terra Board.

Ubuntu, Debian, Linux Mint, Pop!_OS

Download the .deb

Recommended · x64 · install it with your software centre, or in a terminal:

sudo apt install ./terra-board_amd64.deb

Other distributions: AppImage

One file that runs on most distributions and updates itself. It needs FUSE 2 (on Ubuntu 24.04: sudo apt install libfuse2t64).

Download the AppImage 
chmod +x Terra-Board-x86_64.AppImage
./Terra-Board-x86_64.AppImage

On Ubuntu 24.04 and later the AppImage starts with Chromium's sandbox turned off, because the system blocks it for apps outside a package. If you add web pages to your boards, use the .deb.

What's different on Linux

  • Beta: it passes our automated tests on Ubuntu 24.04, but fewer people use it than the Windows version. Tell us what breaks on GitHub or Discord.
  • Updates: the AppImage updates itself. The .deb tells you when a new version is out.
  • Office files need LibreOffice installed (sudo apt install libreoffice).
  • Copy text from images needs Tesseract (sudo apt install tesseract-ocr).
  • The handwriting font is only on Windows; Linux uses a fallback font.
