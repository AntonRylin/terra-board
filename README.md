# Terra Board

A free whiteboard for Windows and Linux. Drop in images, videos, PDFs, notes and links, and arrange them on an infinite canvas. Your boards stay on your computer unless you turn on sync.

**Website:** <https://antonrylin.github.io/terra-board/>

This repository holds only the released installers and the website. The source code is private.

## Download

- **Windows:** [Terra-Board-Setup-x64.exe](https://github.com/AntonRylin/terra-board/releases/latest/download/Terra-Board-Setup-x64.exe) (64-bit installer, always the newest version)
- **Linux (beta):** see the [Linux page](https://antonrylin.github.io/terra-board/linux/)
- **All versions and what changed:** [Releases](https://github.com/AntonRylin/terra-board/releases)

Installed copies update themselves from the releases here.

> Windows may show a SmartScreen warning because the installer isn't code-signed yet. Click **More info → Run anyway**.
